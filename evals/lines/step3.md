Задача. Следующий шаг игры «Lines»: ходы.

Что должно получиться.
1. Щелчок мышью по шарику выбирает его. Выбранный шарик заметно выделен (например, кольцом вокруг). Номер выбранной клетки лежит в данных: вещь app, свойства sel_row и sel_col; 0 значит ничего не выбрано. Щелчок по другому шарику выбирает его вместо прежнего.
2. Если шарик выбран и игрок щёлкает по пустой клетке, шарик переходит туда, но только если есть путь: по пустым клеткам, шагами вверх, вниз, влево, вправо, не по диагонали. Перемещение мгновенное, без анимации. После хода выбор снимается.
3. Если пути нет, ничего не происходит, шарик остаётся выбранным.
4. После каждого удачного хода на случайные пустые клетки добавляется 3 новых шарика случайных цветов. Если пустых клеток меньше трёх, заполняются все оставшиеся.
